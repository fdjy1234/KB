# IP 私有位址區段介紹

私有 IP 位址（Private IP Address）是由 [RFC 1918](https://tools.ietf.org/html/rfc1918) 所定義，專供內部網路使用，**不可在公共網際網路上直接路由**。

---

## 1. 127.0.0.0/8 — Loopback（回環）

> **注意：** 127.0.0.0/8 嚴格來說屬於 **Loopback** 區段，由 RFC 5735 定義，並非 RFC 1918 私有位址，但常與私有區段一併介紹。

| 項目 | 說明 |
|------|------|
| **範圍** | 127.0.0.0 ~ 127.255.255.255 |
| **CIDR** | 127.0.0.0/8 |
| **可用位址數** | 16,777,216 |
| **用途** | 主機自我測試（localhost） |
| **最常用位址** | 127.0.0.1（本機回環） |

### 說明
- 所有送往此區段的封包都**不會離開本機**，由作業系統直接處理。
- 常用於**應用程式自我測試**、服務連線本地端口（如 `http://localhost:3000`）。
- 整個 `/8` 區段皆為 loopback，但實務上幾乎只使用 `127.0.0.1`。

---

## 2. 172.16.0.0/12 — 中型私有網路

| 項目 | 說明 |
|------|------|
| **範圍** | 172.16.0.0 ~ 172.31.255.255 |
| **CIDR** | 172.16.0.0/12 |
| **可用位址數** | 1,048,576（約 100 萬） |
| **RFC** | RFC 1918 |
| **適用場景** | 中型企業、雲端 VPC 內網 |

### 說明
- 涵蓋 `172.16.x.x` 到 `172.31.x.x`，共 **16 個 /16 子網路**。
- 常被雲端服務（如 AWS、GCP、Azure）的 **VPC（虛擬私有雲）** 預設使用。
- Docker 預設的橋接網路（`docker0`）也常使用此區段（如 `172.17.0.0/16`）。

---

## 3. 192.168.0.0/16 — 小型私有網路（最常見）

| 項目 | 說明 |
|------|------|
| **範圍** | 192.168.0.0 ~ 192.168.255.255 |
| **CIDR** | 192.168.0.0/16 |
| **可用位址數** | 65,536 |
| **RFC** | RFC 1918 |
| **適用場景** | 家庭網路、小型辦公室 |

### 說明
- 最常見的私有 IP 區段，幾乎所有家用路由器預設使用（如 `192.168.1.1` 或 `192.168.0.1`）。
- 通常切分成 `/24` 子網（如 `192.168.1.0/24`），可容納 **254 台設備**。
- 因為位址空間較小，適合 **SOHO（小型辦公室/家庭辦公室）** 環境。

---

## 4. 10.0.0.0/8 — 大型私有網路（補充）

> 雖然您未提及，但 RFC 1918 第三個私有區段值得一提：

| 項目 | 說明 |
|------|------|
| **範圍** | 10.0.0.0 ~ 10.255.255.255 |
| **CIDR** | 10.0.0.0/8 |
| **可用位址數** | 16,777,216（約 1600 萬） |
| **RFC** | RFC 1918 |
| **適用場景** | 大型企業、資料中心、骨幹內網 |

---

## 總覽比較表

| 區段 | CIDR | 位址範圍 | 位址數量 | 常見用途 |
|------|------|----------|----------|----------|
| Loopback | 127.0.0.0/8 | 127.0.0.0 ~ 127.255.255.255 | ~1,677 萬 | 本機回環測試 |
| 大型私有 | 10.0.0.0/8 | 10.0.0.0 ~ 10.255.255.255 | ~1,677 萬 | 企業、資料中心 |
| 中型私有 | 172.16.0.0/12 | 172.16.0.0 ~ 172.31.255.255 | ~104 萬 | 雲端 VPC、Docker |
| 小型私有 | 192.168.0.0/16 | 192.168.0.0 ~ 192.168.255.255 | ~6.5 萬 | 家庭、小型辦公室 |

---

## 重點摘要

- 🔒 私有 IP **無法在網際網路上直接通訊**，需透過 **NAT（Network Address Translation）** 轉換。
- ♻️ 私有 IP 可在不同網路中**重複使用**，不會衝突。
- 🏠 `192.168.x.x` → 日常最常見（家用路由器）
- ☁️ `172.16.x.x` → 雲端與容器環境最常見
- 🏢 `10.x.x.x` → 大型組織內網首選
- 🔄 `127.x.x.x` → 本機自我通訊


# CIDR 表示法：`/8`、`/12`、`/16` 是什麼意思？

---

## 基本概念：子網路遮罩（Subnet Mask）

IP 位址由 **32 個 bit** 組成，CIDR 後綴的數字（如 `/8`）代表：

> **前面有幾個 bit 是「網路位址」，剩下的才是「主機位址」**

```
/8  → 前 8  bit 固定（網路） + 後 24 bit 自由（主機）
/12 → 前 12 bit 固定（網路） + 後 20 bit 自由（主機）
/16 → 前 16 bit 固定（網路） + 後 16 bit 自由（主機）
```

---

## 圖解：以 `192.168.0.0/16` 為例

IP 位址用二進位展開：

```
192      . 168      . 0        . 0
11000000 . 10101000 . 00000000 . 00000000
|_______ 固定16bit _______| |__ 自由16bit __|
          網路部分                主機部分
```

`/16` 代表前 16 bit 鎖死 → 只有後 16 bit 可變化
→ 可容納 `2^16 = 65,536` 個位址

---

## 三個區段的 Bit 分析

### `/8` → 10.0.0.0/8

```
10       . 0        . 0        . 0
00001010 . 00000000 . 00000000 . 00000000
|_ 固定 _| |_________ 自由 24 bit _________|

可用位址：2^24 = 16,777,216 個
範圍：10.0.0.0 ~ 10.255.255.255
```

---

### `/12` → 172.16.0.0/12

```
172      . 16       . 0        . 0
10101100 . 00010000 . 00000000 . 00000000
|_ 固定 12 bit _|   |_____ 自由 20 bit ____|

可用位址：2^20 = 1,048,576 個
範圍：172.16.0.0 ~ 172.31.255.255
```

> `/12` 比較特殊，固定的 12 bit 跨越了第一和第二組數字的邊界！

---

### `/16` → 192.168.0.0/16

```
192      . 168      . 0        . 0
11000000 . 10101000 . 00000000 . 00000000
|_______ 固定 16 bit _______| |_ 自由 16 bit _|

可用位址：2^16 = 65,536 個
範圍：192.168.0.0 ~ 192.168.255.255
```

---

## 對應的子網路遮罩（Subnet Mask）

CIDR 可以換算成傳統的子網路遮罩：

| CIDR | 子網路遮罩 | 二進位 |
|------|-----------|--------|
| `/8` | 255.0.0.0 | `11111111.00000000.00000000.00000000` |
| `/12` | 255.240.0.0 | `11111111.11110000.00000000.00000000` |
| `/16` | 255.255.0.0 | `11111111.11111111.00000000.00000000` |
| `/24` | 255.255.255.0 | `11111111.11111111.11111111.00000000` |

> 規律：有幾個 `/`數字 就有幾個 `1`，其餘補 `0`

---

## 生活化比喻

想像 IP 位址像一個「電話號碼」：

```
區碼（固定）    + 個人號碼（自由）
  /8  →  886        + XXXXXXXX    （8  位固定，範圍超大）
  /16 →  886-02     + XXXXXX      （16 位固定，範圍中等）
  /24 →  886-02-123 + XXX         （24 位固定，範圍較小）
```

**固定的部分越少（數字越小）→ 可用的 IP 越多、範圍越大**

---

## 總結對比

| 表示法 | 固定 bit | 自由 bit | 可用 IP 數 | 範圍大小 |
|--------|---------|---------|-----------|---------|
| `/8`  | 8 bit  | 24 bit | **~1,677 萬** | ⭐⭐⭐⭐⭐ 最大 |
| `/12` | 12 bit | 20 bit | **~104 萬**   | ⭐⭐⭐⭐ |
| `/16` | 16 bit | 16 bit | **~6.5 萬**   | ⭐⭐⭐ |
| `/24` | 24 bit | 8 bit  | **256**       | ⭐ 家用常見 |

**結論：`/` 後面的數字越小 → 可用 IP 越多 → 網路範圍越大**
