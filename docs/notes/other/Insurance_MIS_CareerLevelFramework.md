# 產險業資訊人員職能分級框架
## 系統開發人員 ↔ 系統分析師 雙軌發展模式

---

## 概述 (Overview)

本框架專為產險業資訊部門設計，涵蓋**系統開發人員（Developer）** 與 **系統分析師（System Analyst）** 從入門至高階管理層的完整職能分級，並結合企業內部實際職等、核心業務範圍、技術棧、外購系統導入維運能力與法令遵循要求。

### 框架特色
- **從基層到高階職等完整對應**：依企業內部職等由低到高，建立能力成長路徑
- **產險業特化**：融入產險業務特有需求（投保、承保、核保、理賠、通路、再保、投資、B2B、B2C 等）
- **企業核心系統視角**：涵蓋投保、承保、核保、理賠、會計、財務、總務、人事等企業核心流程
- **技術環境明確**：以 **.NET** 為主要開發語言，使用 **TFS** 進行版本控制
- **資料庫與工具明確**：主要資料庫為 **Oracle**，次要為 **SQL Server**；主要工具為 **SQL Developer**，次要工具為 **SQL Server Management Studio**
- **外購系統治理能力納入評估**：一級高級專員以上可規劃和執行外購系統導入與維護
- **法令遵循導向**：以公司內部 **資訊安全管理制度（ISMS）** 為主軸，制度參考個人資料保護法、智慧財產權、保險業自律規範、ISO/IEC 27001 與 ISO/IEC 27002 等要求與最佳實務
- **雙軌發展設計**：兼顧開發與分析能力，並保留跨軌道發展彈性

### 系統範圍
#### 內部開發系統

- B2B
- B2C


#### 外購系統
- 產險理賠聯盟區塊鏈
- CTI 電話客服系統
- 地址正規化系統
- IFRS17 子帳系統
- 要保書影管系統
- KM 知識文件管理系統
- 數位學習系統（E-learning）
- 保單自動裝訂平台系統
- AML 洗錢防制系統
- 營運儀表版系統（Smart eVision）
- 營運報表產出系統（Smart Query）
- FIDO2 服務
- 金財通-公路監理站辨識系統
- ...等

### 核心業務範圍
- **保險核心流程**：投保、承保、核保、理賠
- **企業核心支援流程**：會計、財務、總務、人事
- **經營管理與延伸流程**：通路、再保、投資
- **對外服務與通路**：B2B、B2C
- **管理與控制需求**：權限管理、稽核追蹤、報表、資料交換、主檔管理

### 法令遵循與治理要求
- **公司內部資訊安全管理制度（ISMS）**：主要遵循公司內部資訊安全管理制度（Information Security Management System, ISMS）
- **制度來源基礎**：該制度係參考個人資料保護法、智慧財產權、保險業自律規範、ISO/IEC 27001 與 ISO/IEC 27002 等國際標準之作業要求與最佳實務綜合規劃而成
- **分層要求**：
  - **初階人員**：了解基礎觀念並依制度執行制度作業
  - **中階人員**：配合制度設計作業流程，將控制點導入需求、開發、測試、上線與維運流程
  - **高階人員**：規劃制度、修訂制度，並推動制度治理與持續改善
- **稽核要求**：保留異動紀錄、操作軌跡、資料查詢紀錄與權限審核證據

## 1. 專員（入門級）

### 適用角色
- **開發軌道傾向**：Junior .NET Developer / 程式設計師
- **分析軌道傾向**：Junior Analyst / 業務分析助理
- **通用基礎**：IT 新鮮人、應屆畢業生、轉職人員

### 專員 - 系統開發傾向

#### 硬實力 (Hard Skills)
- **程式語言基礎**
  - 掌握 VB.NET / C# / ASP.NET / .NET Framework 或 .NET Core 基礎
  - 能撰寫基本程式邏輯、表單流程與資料存取程式
  - 理解物件導向程式設計基礎概念

- **開發環境與工具**
  - 熟悉 Visual Studio、SQL Developer 等工具
  - 了解 SQL Server Management Studio 的基本用途
  - 能使用 TFS 進行版本控制（check-in、branch、merge、work item 關聯）
  - 能使用公司內部開發、測試、驗收環境
  - 理解資料庫基本操作（Oracle 為主、SQL Server 為輔）

- **平台與基礎環境**
  - 理解 Windows 11 基本操作、系統設定與常見問題排除
  - 理解 Windows Server 基本觀念，如服務、權限、檔案共享、排程與應用部署環境
  - 了解應用系統與作業系統環境之間的基本關係

- **資訊安全與安全開發**
  - 理解 OWASP Top 10 基本概念與常見風險類型
  - 知道輸入驗證、權限控管、錯誤訊息保護、敏感資料保護等基本要求
  - 了解公司 ISMS 制度下的基本作業規範與開發注意事項

- **產險業務基礎**
  - 理解產險基本商品概念（車險、水險、火險、工程險、責任險、傷害險等）
  - 了解投保、承保、核保、理賠基本流程
  - 能閱讀業務規格書、流程文件與畫面欄位定義
  - 理解內部核心系統主要模組 與周邊系統（投保、理賠、會計、財務、總務、通路、再保、投資、人事、B2B、B2C）

- **測試與品質**
  - 能進行本地功能測試與基本 debug
  - 理解程式碼規範、命名規則與基礎資訊安全要求

#### 軟實力 (Soft Skills)
- 良好的學習態度，主動請教資深同仁
- 能清晰理解與執行分配的開發任務
- 主動回報進度與問題
- 能依據主管或資深人員建議持續修正
- 具備基本的溝通與協作能力

#### 技術策略能力 (Technical Strategy)
- **開發範圍**：理解內部系統架構，能依規範完成功能
- **業務理解**：初步理解產險業務流程，能將簡單需求轉化為開發任務
- **品質意識**：理解測試、資安與制度遵循基本要求的重要性
- **制度遵循**：了解 ISMS 基礎觀念並依制度執行日常作業

### 專員 - 系統分析傾向

#### 硬實力 (Hard Skills)
- **業務分析基礎**
  - 能理解並記錄簡單的業務流程
  - 能繪製基本流程圖（Flowchart）
  - 理解產險商品基本分類與特性
  - 能識別簡單的業務問題與改善點

- **產險業務知識**
  - 深入理解至少 1 種產險商品
  - 掌握該商品的基本流程（投保 → 核保 → 承保 → 理賠）
  - 了解公司 ISMS 基礎制度要求與內部控制觀念
  - 理解保單、批單、賠案等核心概念

- **文件與溝通**
  - 能撰寫簡單的需求說明與測試情境
  - 能使用 Word、Excel 等工具整理分析成果
  - 能進行簡單的需求訪談與問題確認

- **系統認知**
  - 熟悉公司主要業務系統
  - 能閱讀系統架構文件與欄位說明
  - 理解基本資料流與主檔/交易檔概念
  - 理解內部核心系統主要模組 與周邊系統（投保、理賠、會計、財務、總務、通路、再保、投資、人事、B2B、B2C）

#### 軟實力 (Soft Skills)
- 對產險業務有學習熱情
- 能與業務單位進行有效溝通
- 細心、邏輯清晰
- 主動學習業務與系統知識
- 能接受指導並快速改進

#### 技術策略能力 (Technical Strategy)
- **業務理解**：初步掌握產險業務邏輯，能識別改善機會
- **系統認知**：理解系統如何支撐投保到理賠流程
- **需求表達**：能用清楚文字與圖表表達需求
- **制度遵循**：了解 ISMS 基礎觀念並依制度執行制度作業

- 開發：Tech Lead / 系統設計主導
- 分析：Senior Analyst / 模組負責人
- 混合：業務技術整合窗口

### 核心能力要求
- 能主導中型專案或關鍵模組
- 能跨投保、承保、核保、理賠、會計、財務、總務、通路、再保、投資、人事、B2B、B2C 等模組進行整合分析
- 能建立團隊作業標準、需求標準、開發標準與驗測標準
- 能落實制度遵循、資安要求與稽核追蹤機制
- 能帶領 2-5 人團隊執行專案開發或分析工作
- **可規劃外購系統的導入，並主導導入範圍、時程、驗收與維運分工**

### 技術與治理重點
- 具備 OWASP Top 10 實務判斷能力，能要求團隊在設計與開發階段預防常見安全風險
- 理解 Windows Server、應用部署環境與系統整合的管理需求
- 能依公司 ISMS 制度要求設計作業流程與控管點

## 典型 MIS 工作場景

### 開發軌道典型場景
1. **投保/承保系統開發**：建置保單建立、批改、續保與通路介接功能
2. **核保規則引擎**：將產險核保規則轉化為系統邏輯與控管條件
3. **理賠流程自動化**：開發理賠受理、審核、給付與追蹤流程
4. **ERP 整合**：整合會計、財務、總務、人事與保險核心系統資料
5. **B2B / B2C 平台**：支援通路夥伴、業務員與客戶端服務流程
6. **外購系統整合維護**：串接 CTI、IFRS17 子帳、AML、FIDO2、影管、報表平台等系統

### 分析軌道典型場景
1. **新商品上線分析**：分析新產險商品的流程、規則與系統需求
2. **跨部門流程優化**：優化投保、核保、承保、理賠與財務串接流程
3. **制度與內控需求落地**：將 ISMS 制度要求轉為系統控制點與作業流程
4. **系統整合規劃**：規劃 ERP、外購系統與內部周邊系統整合
5. **數位轉型**：推動線上服務、自動化流程與資料驅動決策

### 混合軌道典型場景
1. **核心系統現代化**：從需求分析到 .NET 技術重構與交付
2. **制度系統化**：將權限、異動紀錄、稽核與安全要求內嵌到系統設計
3. **端到端專案推動**：從業務需求、系統設計、開發驗測到正式上線
4. **跨模組整合**：串接保險核心流程、B2B/B2C 與外購平台
5. **客戶與通路體驗優化**：改善 B2B/B2C 操作流程與服務效率

4. **組織能力**：人才梯隊、制度建立、跨部門資源整合

6. **外購系統治理**：供應商策略、架構整合、導入原則與投資優先序

## 備註

1. **職級評估不僅看年資**：應以實際能力、貢獻、影響力與制度落實程度綜合評估
2. **技術主軸明確**：內部開發以 **.NET** 為主，資料庫以 **Oracle** 為主、**SQL Server** 為輔
3. **工具標準明確**：主要資料庫工具為 **SQL Developer**，次要為 **SQL Server Management Studio**
4. **版控流程一致**：以 **TFS** 為主要版本控制與工作項目管理工具
5. **安全能力必須具備**：開發人員應逐級強化對 **OWASP Top 10** 與安全開發的理解與實踐
6. **作業系統理解納入能力要求**：應理解 Windows 11 與 Windows Server 在應用開發與維運中的角色
7. **業務範圍廣泛**：MIS 支援的不僅是保險核心流程，也包括 ERP、外購系統與對外通路平台
8. **制度遵循必須內建**：主要遵循公司內部 **ISMS**，並由初階執行、中階設計流程、高階規劃修訂
9. **鼓勵雙向發展**：具業務與技術整合能力的人才，特別適合推動產險業數位轉型與流程優化
