# 產險業 MIS 人員職能分級框架
## 系統開發人員 ↔ 系統分析師 雙軌發展模式

---

## 概述 (Overview)

本框架專為產險業內部 MIS（管理資訊系統）部門設計，涵蓋**系統開發人員（Developer）** 與 **系統分析師（System Analyst）** 從入門至高階管理層的完整職能分級，並結合企業內部實際職等、核心業務範圍、技術棧與法令遵循要求。

### 框架特色
- **從基層到高階職等完整對應**：依企業內部職等由低到高，建立能力成長路徑
- **產險業特化**：融入產險業務特有需求（投保、承保、核保、理賠、B2B、B2C 等）
- **企業 ERP 視角**：涵蓋投保、承保、核保、理賠、會計、財務、總務等企業核心流程
- **技術環境明確**：以 **.NET** 為主要開發語言，使用 **TFS** 進行版本控制
- **法令遵循導向**：納入**保險業自律規範**與**ISO 27001**等要求
- **雙軌發展設計**：兼顧開發與分析能力，並保留跨軌道發展彈性

## 1. 專員（入門級）

### 適用角色
- **開發軌道傾向**：Junior .NET Developer / 程式設計師
- **分析軌道傾向**：Junior Analyst / 業務分析助理
- **通用基礎**：IT 新鮮人、應屆畢業生、轉職人員

### 專員 - 系統開發傾向

#### 硬實力 (Hard Skills)
- **程式語言基礎**
  - 掌握 C# / ASP.NET / .NET Framework 或 .NET Core 基礎
  - 能撰寫基本程式邏輯、表單流程與資料存取程式
  - 理解物件導向程式設計基礎概念

- **開發環境與工具**
  - 熟悉 Visual Studio、SQL Server Management Studio 等工具
  - 能使用 TFS 進行版本控制（check-in、branch、merge、work item 關聯）
  - 能使用公司內部開發、測試、驗收環境
  - 理解資料庫基本操作（SQL 基本 CRUD）

- **產險業務基礎**
  - 理解產險基本商品概念（車險、火險、責任險、旅平險等）
  - 了解投保、承保、核保、理賠基本流程
  - 能閱讀業務規格書、流程文件與畫面欄位定義
  - 理解企業 ERP 與周邊系統主要模組（投保、理賠、會計、財務、總務、B2B、B2C）

- **測試與品質**
  - 能撰寫簡單單元測試
  - 能進行本地功能測試與基本 debug
  - 理解程式碼規範、命名規則與基礎資訊安全要求

#### 軟實力 (Soft Skills)
- 良好的學習態度，主動請教資深同仁
- 能清晰理解與執行分配的開發任務
- 主動回報進度與問題
- 能依據 code review 或主管建議持續修正
- 具備基本的溝通與協作能力

#### 技術策略能力 (Technical Strategy)
- **開發範圍**：理解三層式或 N-tier 架構，能依規範完成功能
- **業務理解**：初步理解產險業務流程，能將簡單需求轉化為開發任務
- **品質意識**：理解測試與法遵基本要求的重要性

### 專員 - 系統分析傾向

#### 硬實力 (Hard Skills)
- **業務分析基礎**
  - 能理解並記錄簡單的業務流程
  - 能繪製基本流程圖（Flowchart / BPMN 簡易版）
  - 理解產險商品基本分類與特性
  - 能識別簡單的業務問題與改善點

- **產險業務知識**
  - 深入理解至少 1 種產險商品
  - 掌握該商品的基本流程（投保 → 核保 → 承保 → 理賠）
  - 了解保險業自律規範與基本內控制度要求
  - 理解保單、批單、賠案等核心概念

- **文件與溝通**
  - 能撰寫簡單的需求說明與測試情境
  - 能使用 Visio、PowerPoint、Excel 等工具整理分析成果
  - 能進行簡單的需求訪談與問題確認

- **系統認知**
  - 熟悉公司主要業務系統與 ERP 流程
  - 能閱讀系統架構文件與欄位說明
  - 理解基本資料流與主檔/交易檔概念

#### 軟實力 (Soft Skills)
- 對產險業務有學習熱情
- 能與業務單位進行有效溝通
- 細心、邏輯清晰
- 主動學習業務與系統知識
- 能接受指導並快速改進

#### 技術策略能力 (Technical Strategy)
- **業務理解**：初步掌握產險業務邏輯，能識別改善機會
- **系統認知**：理解系統如何支撐投保到理賠流程
- **需求表達**：能用清楚文字與圖表表達需求

## 2. 二級高級專員（初階進階）

### 適用角色
- **開發軌道傾向**：.NET Developer / 系統開發人員
- **分析軌道傾向**：Business Analyst / 系統分析人員
- **通用**：可獨立完成模組內任務

### 二級高級專員 - 系統開發傾向

#### 硬實力 (Hard Skills)
- 精通至少 1 種主要 .NET 技術（C#、ASP.NET MVC、Web API、Entity Framework 等）
- 能撰寫結構清晰、可維護的程式碼
- 能進行 SQL Server 資料表設計、Stored Procedure 撰寫與效能基礎調校
- 能依需求開發 API、批次作業、報表功能或 ERP 模組功能
- 熟悉 TFS 工作流程與版本管理規範
- 理解產險商品、核保規則、理賠流程與基礎法遵要求
- 了解 ISO 27001 相關資訊安全控制重點，如權限控管、異動留痕、資料保護

#### 軟實力 (Soft Skills)
- 能與分析師、測試人員、業務單位合作完成任務
- 能提出技術風險與限制
- 願意分享技術知識並協助新人
- 能將需求轉換為具體功能設計

#### 技術策略能力 (Technical Strategy)
- **架構參與**：能參與模組級設計與資料流程討論
- **業務映射**：能將產險業務規則映射到程式邏輯
- **品質策略**：能遵循開發標準、測試流程與資安規範

### 二級高級專員 - 系統分析傾向

#### 硬實力 (Hard Skills)
- 能獨立分析中等複雜度的業務流程與系統需求
- 熟悉投保、承保、核保、理賠、B2B、B2C 等模組流程
- 能撰寫需求規格書、流程圖、欄位對照與測試案例
- 能識別跨系統資料流、介接需求與例外流程
- 理解保險業自律規範、ISO 27001 對系統流程與文件留存的要求

#### 軟實力 (Soft Skills)
- 能與多個業務單位進行需求溝通
- 能整理需求差異與優先順序
- 能從業務角度提出改善建議
- 能建立與使用單位的信任關係

#### 技術策略能力 (Technical Strategy)
- **需求策略**：能將部門需求轉化為可執行的系統需求
- **風險管理**：可初步識別流程、法遵與系統風險
- **價值交付**：聚焦於流程效率與使用者體驗改善

## 業務範圍與系統職能地圖

### 核心業務範圍
- **保險核心流程**：投保、承保、核保、理賠
- **企業 ERP 支援流程**：會計、財務、總務
- **對外服務與通路**：B2B、B2C
- **管理與控制需求**：權限管理、稽核追蹤、報表、資料交換、主檔管理

### 法令遵循與治理要求
- **保險業自律規範**：確保流程、權限、資料留存與作業管控符合保險業內控與自律要求
- **ISO 27001**：落實資訊資產管理、存取控制、變更管理、事件追蹤、備援與持續改善
- **稽核要求**：保留異動紀錄、操作軌跡、資料查詢紀錄與權限審核證據

## 典型 MIS 工作場景

### 開發軌道典型場景
1. **投保/承保系統開發**：建置保單建立、批改、續保與通路介接功能
2. **核保規則引擎**：將產險核保規則轉化為系統邏輯與控管條件
3. **理賠流程自動化**：開發理賠受理、審核、給付與追蹤流程
4. **ERP 整合**：整合會計、財務、總務與保險核心系統資料
5. **B2B / B2C 平台**：支援通路夥伴、業務員與客戶端服務流程

### 分析軌道典型場景
1. **新商品上線分析**：分析新產險商品的流程、規則與系統需求
2. **跨部門流程優化**：優化投保、核保、承保、理賠與財務串接流程
3. **法遵與內控需求落地**：將自律規範、ISO 27001 要求轉為系統控制點
4. **系統整合規劃**：規劃 ERP 與外部通路、內部周邊系統整合
5. **數位轉型**：推動線上服務、自動化流程與資料驅動決策

### 混合軌道典型場景
1. **核心系統現代化**：從需求分析到 .NET 技術重構與交付
2. **法遵系統化**：將稽核、權限、異動紀錄要求內嵌到系統設計
3. **端到端專案推動**：從業務需求、系統設計、開發驗測到正式上線
4. **跨模組整合**：串接保險核心流程與 ERP/通路平台
5. **客戶與通路體驗優化**：改善 B2B/B2C 操作流程與服務效率

## 人才培養與發展建議

### 初階培養重點（專員～二級高級專員）
1. **技術基礎**：.NET、SQL Server、Visual Studio、TFS
2. **業務基礎**：產險商品、投保/承保/核保/理賠流程、ERP 基礎
3. **法遵認知**：保險業自律規範、ISO 27001、基本內控與稽核要求
4. **工作方法**：需求閱讀、文件撰寫、測試、自我管理

### 中階培養重點（一級高級專員～專案副理）
1. **技術深化**：系統設計、整合架構、資料庫效能、批次/API 設計
2. **分析深化**：複雜流程分析、需求控管、跨部門協調
3. **法遵落地**：將規範、稽核、權限與留痕需求轉化為系統控制機制
4. **領導能力**：帶人、帶案、風險管理、溝通協調

### 高階培養重點（專案經理～專案副總經理）
1. **治理能力**：專案治理、技術治理、資安治理、法遵治理
2. **企業視角**：IT 與業務整合、數位轉型、ERP 策略
3. **組織能力**：人才梯隊、制度建立、跨部門資源整合
4. **戰略規劃**：年度計畫、中長期系統藍圖與投資效益評估

## 備註

1. **職級評估不僅看年資**：應以實際能力、貢獻、影響力與法遵落實程度綜合評估
2. **技術主軸明確**：內部開發以 **.NET** 為主，相關能力應作為主要評估基礎
3. **版控流程一致**：以 **TFS** 為主要版本控制與工作項目管理工具
4. **業務範圍廣泛**：MIS 支援的不僅是保險核心流程，也包括 ERP 與對外通路系統
5. **法遵與資安必須內建**：保險業自律規範與 ISO 27001 不應只是附加要求，而應內嵌於需求、設計、開發、測試與上線流程
6. **鼓勵雙向發展**：具業務與技術整合能力的人才，特別適合推動產險業數位轉型與流程優化
